# Мой киносписок

Русскоязычная личная лента фильмов и сезонов. В каталоге хранятся описания, постеры, расписания и ссылки на YouTube. Каждая отметка просмотра и каждая отметка «Любимые» хранятся отдельно по ID карточки.

Кнопка «Поделиться сайтом» копирует общий адрес каталога или открывает системное меню отправки. На GitHub Pages все пять вкладок доступны сразу. При первом добавлении или снятии отметки сайт спрашивает четырёхзначный пароль. После подтверждения сайт выполняет выбранное действие и запоминает разрешение в этом браузере. Обычное закрытие браузера сохраняет разрешение. Очистка данных сайта удаляет и разрешение, и сохранённые в этом браузере отметки.

## Запуск и публикация

Для просмотра без сервера откройте в браузере отдельный файл `dist/Мой киносписок.html`. После изменений каталога его обновляет `npm run build`. Для разработки выполните `npm run dev` в папке проекта и откройте адрес из терминала. Достаточно Node.js 22. Локальный сайт хранит отметки и тему в браузере.

Для GitHub Pages поместите содержимое этой папки в корень собственного репозитория. В **Settings → Pages** выберите **Deploy from a branch**, ветку публикации и **/(root)**. Путь к каталогу и изображениям относительный, поэтому сайт работает и в подпапке репозитория. После push Pages обновляет ленту. На статическом адресе история хранится в браузере. Можно также опубликовать только содержимое `dist/pages` после `npm run build`.

В исходниках подготовлен серверный вариант для приватного Sites с базой D1. После публикации платформа ограничивает доступ аккаунтом владельца и передаёт идентификатор серверу. На обоих устройствах используется один приватный адрес. Изменение отметки сразу отправляется на сервер. При возврате в окно история перечитывается, открытая вкладка обновляется каждые 30 секунд. Локальный и серверный режимы используют отдельные истории. Для изменения схемы установите dev-зависимости через `npm ci` и выполните `npm run db:generate`.

После правок интерфейса выполните `npm run build` перед коммитом. Сборка обновит версии в ссылках на изменённые стили и скрипты. Включите обновлённые `index.html` и `app.js` в тот же коммит, чтобы при следующем открытии страницы браузер загрузил нужные файлы.

## Добавление через Codex

Найдите фильм или сезон по TMDB. Если неоднозначны экранизация, год или сезон, уточните выбор. Сверьте дату премьеры, студии, платформы, трейлер и расписание с правообладателем. Сохраняйте русский заголовок, краткое русское описание и подтверждённые жанры. В поле `trailer` указывайте прямую ссылку YouTube на официальный трейлер или тизер этого фильма или сезона. Если ролика нет, оставьте поле пустым. Используйте IMDb с подписью источника или явно обозначенный рейтинг ожидания. Оценка всего сериала подписывается отдельно.

Запись имеет формат существующих объектов в `catalog.json`. Для фильма используйте ID `tmdb-movie-<id>`, для сезона — `tmdb-tv-<id>-s<номер>`. У одного сериала может быть несколько карточек с разными номерами сезонов. ID сохраняется при исправлении названия и даты. Студии храните в массиве `studios`, платформы — в `platforms`. Фильтр охватывает оба поля. Для фильтров используйте названия Apple, Amazon, Netflix, Disney и HBO. Добавляйте только подтверждённые связи.

Поле `origin` задаёт категорию по стране производства. Укажите `russian`, если среди стран производства есть Россия, в том числе при совместном производстве. Для зарубежных проектов укажите `foreign`. Если страны пока неизвестны, укажите `null`. Такие записи видны при выборе «Все страны» и идут в конце при сортировке по стране.

Передайте полный JSON одной записи в `node scripts/save-entry.mjs` через стандартный ввод. Команда обновит `catalog.json`, поставит дату добавления для новой карточки и сохранит исходную дату при правках. Неизвестные даты и оценки храните как `null`. Сохраните ссылки на источники, затем выполните `npm run build` и отправьте изменения в ветку публикации.

В «Жду» видны будущие премьеры без личных отметок. В дату премьеры карточка переходит в «Новинки». Чтобы добавить фильм или сезон в «Старое», попросите Codex добавить название именно туда. Для такой записи укажите `"status": "backlog"` независимо от года выхода. При обновлении описания или расписания сохраняйте этот статус.

Отметка просмотра убирает карточку из исходной ленты. При снятии отметки она возвращается, в том числе в «Старое». Добавление в любимые убирает карточку из «Жду». Обе личные отметки независимы, их можно снять отдельно. Карточка показывает дату добавления и даты действующих отметок. Для старой отметки без сохранённого времени выводится «Дата неизвестна».
