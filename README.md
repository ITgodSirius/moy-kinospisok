# Мой киносписок

Русскоязычная личная лента фильмов и сезонов. В каталоге хранятся описания, постеры, расписания и ссылки на трейлеры. Каждая отметка просмотра и каждая отметка «Любимые» хранятся отдельно по ID карточки.

Все разделы основного сайта доступны для чтения по одной ссылке. Общие отметки и их даты находятся в файле `watch-history.json` ветки `watch-history` репозитория `ITgodSirius/moy-kinospisok`. Загрузка и запись идут напрямую через GitHub.

## Запуск и публикация

Для просмотра без сервера откройте в браузере отдельный файл `dist/Мой киносписок.html`. После изменений каталога его обновляет `npm run build`. Для разработки выполните `npm run dev` в папке проекта и откройте адрес из терминала. Достаточно Node.js 22. Локальная и автономная версии показывают прежние отметки из браузера. Менять общую историю можно на основном сайте GitHub Pages.

Для GitHub Pages поместите содержимое этой папки в корень собственного репозитория. В **Settings → Pages** выберите **Deploy from a branch**, ветку публикации и **/(root)**. Путь к каталогу и изображениям относительный, поэтому сайт работает и в подпапке репозитория. После push Pages обновляет ленту. На основном адресе при первом изменении укажите в киносписке личный ключ GitHub для этого браузера. В настройках fine-grained token выберите только репозиторий `moy-kinospisok` и право Contents → Read and write. Ключ хранится на устройстве. Вставьте ключ и нажмите Enter или «Готово» на телефоне. При подключении сайт переносит прежние локальные отметки. При одновременной записи сайт перечитывает файл и повторяет только своё изменение. Гости видят историю при открытии, возвращении на вкладку и каждые 30 секунд в активном окне.

В исходниках подготовлен серверный вариант для приватного Sites с базой D1. После публикации платформа ограничивает доступ аккаунтом владельца и передаёт идентификатор серверу. На обоих устройствах используется один приватный адрес. Серверный вариант открывает прежнюю историю только для чтения. При возврате в окно история перечитывается, открытая вкладка обновляется каждые 30 секунд. Локальный и серверный режимы используют отдельные истории. Для изменения схемы установите dev-зависимости через `npm ci` и выполните `npm run db:generate`.

После правок интерфейса выполните `npm run build` перед коммитом. Сборка обновит версии в ссылках на изменённые стили и скрипты. Включите обновлённые `index.html` и `app.js` в тот же коммит, чтобы при следующем открытии страницы браузер загрузил нужные файлы.

## Добавление через Codex

Для мультфильма или мультсериала укажите в `genres` жанр «Мультфильм», если он подтверждён. Карточка автоматически появится в категории «Мультики». Поле `type` по-прежнему задаёт формат фильма или сезона.

Для сезона дорамы укажите `"type": "series"` и `"dorama": true`. Тогда сезон будет виден и в «Дорамах», и в «Сериалах». В `genres` указывайте жанры самого сериала.

Найдите фильм или сезон по TMDB. Если неоднозначны экранизация, год или сезон, уточните выбор. Сверьте дату премьеры, студии, платформы, трейлер и расписание с правообладателем. Сохраняйте русский заголовок, краткое русское описание и подтверждённые жанры. Используйте IMDb с подписью источника или явно обозначенный рейтинг ожидания. Оценка всего сериала подписывается отдельно.

Для новой карточки обязательна прямая ссылка на трейлер или тизер именно этого фильма или сезона в поле `trailer`. Используйте YouTube или Rutube. Для выпущенных фильмов подходит проверенная архивная копия оригинального трейлера. Если подходящий ролик ещё не опубликован, держите новую карточку в черновике до его появления.

Запись имеет формат существующих объектов в `catalog.json`. Для фильма используйте ID `tmdb-movie-<id>`, для сезона — `tmdb-tv-<id>-s<номер>`. У одного сериала может быть несколько карточек с разными номерами сезонов. ID сохраняется при исправлении названия и даты. Студии храните в массиве `studios`, платформы — в `platforms`. Фильтр охватывает оба поля. Для фильтров используйте названия Apple, Amazon, Netflix, Disney и HBO. Добавляйте только подтверждённые связи.

Поле `origin` задаёт категорию по стране производства. Укажите `russian`, если среди стран производства есть Россия, в том числе при совместном производстве. Для зарубежных проектов укажите `foreign`. Если страны пока неизвестны, укажите `null`. Такие записи видны при выборе «Все страны» и идут в конце при сортировке по стране.

Передайте полный JSON одной записи в `node scripts/save-entry.mjs` через стандартный ввод. Команда обновит `catalog.json`, поставит дату добавления для новой карточки и сохранит исходную дату при правках. Неизвестные даты и оценки храните как `null`. Сохраните ссылки на источники, затем выполните `npm run build` и отправьте изменения в ветку публикации.

В «Жду» видны будущие премьеры без личных отметок. В день премьеры по местному времени карточка переходит в «Новинки», даже если вкладка была открыта с вечера. У каждой карточки тонкая серая рамка. В день выхода фильма или сезона и следующие девять календарных дней рамка золотая. Чтобы добавить фильм или сезон в «Старое», попросите Codex добавить название именно туда. Для такой записи укажите `"status": "backlog"` независимо от года выхода. При обновлении описания или расписания сохраняйте этот статус.

Кнопка «Смотрю сейчас» переносит фильм или сезон в одноимённую вкладку и сохраняет дату начала просмотра. «Отложить просмотр» снимает эту отметку. «Отметить просмотренным» переносит карточку в «Просмотрено». Если снять отметку о завершении, карточка вернётся в «Смотрю сейчас», если просмотр был начат, или в исходную ленту. Пока стоит отметка «Любимые», карточка видна только в этой ленте. После снятия сердца карточка возвращается в ленту по текущему статусу. Даты просмотра и личная оценка сохраняются. В истории карточки видны дата добавления и даты отметок. Для старой отметки без сохранённого времени выводится «Дата неизвестна».

При сохранении карточки сериала скрипт загружает с TMDB все сезоны и серии, объединяет их с проверенным расписанием и обновляет карточки того же сериала. Окно «Сезоны и серии» работает и в офлайн-сборке. Если готовое расписание уже сверено вручную, передайте его в поле `seasons` и запустите `node scripts/save-entry.mjs --verified-seasons`. У объявленной серии без даты укажите `date: null`.

В истории просмотренного фильма или сезона можно выбрать одну оценку: «Понравилось», «Нейтрально» или «Не понравилось». Повторное нажатие снимает её. Оценка и её дата сохраняются вместе с личной историей просмотра.

## Мой вишлист

Нажмите на заголовок «Мой киносписок», чтобы открыть вишлист. Повторное нажатие на заголовок возвращает к той же ленте. Галочка перемещает желание между вкладками «Хочу» и «Сбылось». На основном адресе отметки желаний синхронизируются вместе с киносписком.

Добавляйте желания через Codex в `wishlist.json`. Для записи укажите стабильный `id` с префиксом `wish-`, `title`, `addedDate` в формате `ГГГГ-ММ-ДД` и `category`: `things` (вещи), `trips` (поездки), `experiences` (впечатления) или `perfume` (духи). Можно указать `note`, `description`, `budget` в рублях, `url`, локальное `image` в `assets/` и `imageSource`. При правках сохраняйте ID и дату добавления. После обновления запустите `npm run build`.

## Мои цитаты

«Мои цитаты» и «Тренировки» доступны на основном сайте после проверки ключа владельца через GitHub. Публичные киносписок и вишлист открываются без ключа.

Тренировки, БЖУ и замеры сохраняются в `training.json`, цитаты — в `quotes.json`. Оба файла находятся в ветке `watch-history` того же репозитория, рядом с историей кино. Они появляются при первой записи. Для сохранения подходит существующий ключ с правом Contents → Read and write для `moy-kinospisok`. На GitHub файлы доступны для чтения по прямой ссылке.

Для подготовки цитаты передайте запись через стандартный ввод команды `node scripts/save-quote.mjs /путь/к/рабочей/папке/watch-history`. Затем закоммитьте `quotes.json` в этой рабочей папке и отправьте его в ветку `watch-history`.
